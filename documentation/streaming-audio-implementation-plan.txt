# Streaming Audio Processing Implementation Plan

## Overview

This plan outlines a strategy to implement streaming audio processing to reduce latency in our voice-to-text processing pipeline. We've implemented an HTTP-based chunked processing approach to work within VPN restrictions that prevent WebSockets usage.

## Current Performance (May 2023)

Our latest optimizations have achieved significant improvements in latency:

- **End-to-End Latency**: ~5 seconds total (with ~2.5 seconds of actual processing after speech ends)
- **Audio Blob Creation**: Reduced from 1626ms to 217-366ms using WebWorkers
- **Azure API Processing**: Reduced to ~1200-1400ms (from 1700+ms) with parameter optimization
- **Chat API Processing**: Reduced to ~400-650ms with connection pre-warming and parameter tuning

Key improvements implemented:

1. **WebWorker Processing**: Offloaded audio processing to a separate thread
2. **API Connection Pre-warming**: Established connections before recording starts
3. **Parallel Processing**: Implemented concurrent operations for audio processing
4. **Format-Specific Optimizations**: Streamlined audio format detection and handling
5. **API Parameter Tuning**: Optimized Azure and OpenAI API parameters for speed

## Performance Bottlenecks Analysis

Current bottlenecks in order of priority:
1. **Azure API Call** (~1200-1400ms): Still the longest single operation
2. **Audio Processing** (~300-400ms): WebWorker implementation is effective
3. **Chat API** (~400-650ms): Significant improvement with proper parameters

## Phase IV Optimization Targets

To reach our target of 1-2 seconds of post-speech processing:

1. **Azure API Parameter Fine-tuning**: Continue refining parameters based on test results
2. **Implement Streaming Response Handling**: Display partial responses as they arrive
3. **Format-Specific Compression**: Further optimize audio formats based on detected types
4. **Chat API Context Management**: Optimize prompt size and context window usage
5. **UI Optimizations**: Implement progressive rendering to improve perceived performance

## Completed Optimizations

### 1. WebWorker Audio Processing Implementation

```typescript
// audioWorker.ts - Worker for processing audio in a separate thread
export interface AudioWorkerInput {
  type: 'PROCESS_AUDIO';
  chunks: ArrayBuffer[];  // Audio chunks as array buffers
  mimeType: string;       // Original MIME type
  isLastChunk: boolean;   // Whether this is the final chunk
}

// Optimized audio processing in worker thread
function optimizeAudioBlob(chunks: ArrayBuffer[], mimeType: string, isLastChunk: boolean): { blob: Blob, mimeType: string } {
  // Special cases for empty or tiny chunks
  if (chunks.length === 0) return { blob: new Blob([], { type: "audio/mpeg" }), mimeType: "audio/mpeg" };
  if (chunks.length === 1 && chunks[0].byteLength < 10000) {
    return { blob: new Blob([chunks[0]], { type: mimeType || "audio/mpeg" }), mimeType: mimeType || "audio/mpeg" };
  }
  
  // Format optimization based on chunk type
  const outputMimeType = isLastChunk ? "audio/mpeg" : mimeType;
  
  // Create optimized blob
  const blob = new Blob(chunks, { type: outputMimeType });
  return { blob, mimeType: outputMimeType };
}
```

### 1. Implement Azure API Streaming Mode (Priority)

Implement partial transcription display as results arrive from Azure:

```typescript
// In StreamingVoiceTest.tsx
function processStreamingTranscription(chunk: AudioChunk) {
  // Process audio in parallel with displaying interim results
  setPartialText("Processing your speech...");
  
  const processingPromise = processAudioChunk(chunk.blob, sessionInfo, chunk.isLastChunk);
  
  // Set up a polling mechanism to check for partial results
  let pollCount = 0;
  const maxPolls = 10;
  const pollInterval = setInterval(async () => {
    pollCount++;
    try {
      // Check for partial results
      const partialResult = await fetch(`/api/transcribe-status/${sessionInfo.sessionId}`);
      const data = await partialResult.json();
      
      if (data.partialText) {
        setPartialText(data.partialText);
      }
      
      // Stop polling after max tries or when processing is done
      if (pollCount >= maxPolls) {
        clearInterval(pollInterval);
      }
    } catch (error) {
      console.error("Error polling for partial results:", error);
    }
  }, 200);
  
  // Process the full result when available
  return processingPromise;
}
```

### 2. Optimize Audio Format Based on Dynamic Detection

```typescript
// In transcribe-chunk/route.ts
function getOptimizedFormat(audioBlob: Blob, isLastChunk: boolean): { blob: Blob, extension: string } {
  const size = audioBlob.size;
  const type = audioBlob.type;
  
  // For very small chunks (<5KB), prioritize speed over format consistency
  if (size < 5000 && !isLastChunk) {
    return { blob: audioBlob, extension: detectAudioFormatCached(type) };
  }
  
  // For final chunks, prioritize MP3 format for quality vs size balance
  if (isLastChunk) {
    // If already MP3, don't convert
    if (type.includes('mp3') || type.includes('mpeg')) {
      return { blob: audioBlob, extension: 'mp3' };
    }
    
    // Try to convert to MP3
    return { 
      blob: convertToOptimizedFormat(audioBlob, 'audio/mpeg'),
      extension: 'mp3'
    };
  }
  
  // For interim chunks, use smallest format based on content
  return { 
    blob: audioBlob,
    extension: detectAudioFormatCached(type)
  };
}
```

### 3. Implement Progressive UI Rendering

```tsx
// In StreamingVoiceTest.tsx
function renderProgressiveResponse(partialResponse: string | null, finalResponse: string | null) {
  const [displayText, setDisplayText] = useState("");
  
  // Update display text when responses change
  useEffect(() => {
    if (finalResponse) {
      // If we have a final response, show it immediately
      setDisplayText(finalResponse);
    } else if (partialResponse) {
      // If we have a partial response, show it with typing animation
      let currentIndex = 0;
      const text = partialResponse;
      
      const typingInterval = setInterval(() => {
        if (currentIndex <= text.length) {
          setDisplayText(text.substring(0, currentIndex));
          currentIndex++;
        } else {
          clearInterval(typingInterval);
        }
      }, 20);
      
      return () => clearInterval(typingInterval);
    }
  }, [partialResponse, finalResponse]);
  
  return (
    <div className="response-container">
      <div className="response-text">{displayText}</div>
      {!finalResponse && partialResponse && <div className="thinking-indicator">...</div>}
    </div>
  );
}
```

function getOptimizedPrompt(transcription: string) {
  // Detect greetings
  if (/^(hi|hello|hey|greetings|howdy)/i.test(transcription)) {
    return OPTIMIZED_PROMPT_TEMPLATES.greeting;
  }
  
  // Detect simple questions
  if (transcription.length < 20 && transcription.includes('?')) {
    return OPTIMIZED_PROMPT_TEMPLATES.quickResponse;
  }
  
  // Default template
  return OPTIMIZED_PROMPT_TEMPLATES.standard;
}
